## 🚀 Quick Install on Android Emulators

1. Download **`MACRIC.apk`** from the link above (or from the GitHub Actions artifact).
2. Open your emulator (**BlueStacks 5**, **LDPlayer 9**, or **MSI App Player**).
3. **Drag & drop** the `MACRIC.apk` file directly onto the emulator window.
4. Launch **MACRIC** from the home screen.
5. Tap **HUD ON** and enable **"Display over other apps"** (Overlay permission) when prompted.
6. Connect your game, customize your reticle, and enjoy pinpoint aim!

## 🛠️ Automated Cloud APK Build (GitHub Actions)

You **do not** need to install Android Studio or configure Gradle on your computer. This repository automatically compiles the APK using **GitHub Actions**:

1. Go to the **Actions** tab of this repository.
2. Under *Workflows*, select **Build Android APK**.
3. Click **Run workflow** > select `main` > click **Run workflow**.
4. Once completed (approx. 2 minutes), download the **`MACRIC-APK`** artifact zip.
5. Extract the zip and install `MACRIC.apk`.

## ✨ Features

- 🎯 **Custom Crosshair Engine:** Dot, Cross, Circle, Chevron, Diamond, T-Shape, and Circle-Dot with customizable size, gap, thickness, and color.
- 🔥 **Fire Button HUD:** Drag & position custom-calibrated trigger buttons.
- ⚡ **Sensitivity Tuner:** General, Red Dot, 2X, 4X, and Sniper sensitivities with custom profiles.
- 🎮 **Emulator-Optimized:** Zero native NDK libraries; runs seamlessly on x86, x86_64, and ARM emulators.
- 🛡️ **100% Fair Play:** Zero aimbots, zero memory reading, zero macros, and zero game file modification. Visual overlay only.

---

## ⚖️ Fair Play Guarantee
MACRIC strictly adheres to gaming fair-play standards:
- It **never** interacts with game memory or processes.
- It **never** injects code or alters game files.
- It operates purely as an independent floating Android HUD overlay (`SYSTEM_ALERT_WINDOW`).
